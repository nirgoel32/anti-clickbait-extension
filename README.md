# AI-Powered Clickbait Detection Extension

## Introduction
This extension uses artificial intelligence to detect and warn users about clickbait headlines. Clickbait refers to headlines designed to attract attention and entice readers to click on them, often leading to misleading content.

## Features
- **Real-Time Detection**: Analyzes headlines in real-time as you browse.
- **User-Friendly Interface**: Provides feedback directly in the browser with an intuitive design.
- **Customizable Settings**: Users can adjust the sensitivity of the clickbait detection algorithm.
- **Analytics Dashboard**: Users can track their exposure to clickbait over time.

## Installation
1. Clone the repository:
   ```bash
   git clone https://github.com/nirgoel32/anti-clickbait-extension.git
   ```
2. Open your browser and go to the extensions section.
3. Enable Developer Mode.
4. Click on Load unpacked and select the cloned directory.

## Usage
After installation, the extension automatically analyzes text for clickbait characteristics. 
- **Green Indicator**: No clickbait detected.
- **Yellow Indicator**: Possible clickbait detected.
- **Red Indicator**: Confirmed clickbait detected.

## AI Model
The detection is powered by a trained machine learning model that has been fine-tuned on a dataset of known clickbait and non-clickbait headlines.
